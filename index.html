Find the Third

A short learning level that teaches new SET players to find a set in a 6-card layout with one idea: any two cards decide the third.

User story

As a new player who knows the rules of SET but freezes when looking at a full board, I want a reliable way to find a set without checking every combination, so that I can keep up with other players in a real game.

How the level works

Design decisions

  • The ghost card makes the hidden step visibleExperienced players picture the missing card in their head. The ghost card shows that picture on screen, then disappears once the player can do it alone.
  • Six cards, exactly one setA 6-card board has 20 possible triples instead of 220 on a 12-card board, so the strategy can be learned before the search gets large.
  • One screen layout from start to finishOnly the supports change between steps (ghost card, hints, timer), so the player never has to relearn the interface.
  • Feedback colors that don't clash with the cardsCorrect is teal and incorrect is orange, so feedback is never confused with the red, green, and purple on the cards.
  • Feedback explains every attributeCorrect answers list all four attributes. Wrong answers name only the attributes that broke the rule, so the player knows exactly what to fix.
  • A way back after a failed challengeScoring below 8/10 sends the player back to guided practice with the ghost card instead of ending the level.

Design notes

How each step of the level handles the three kinds of cognitive load. Letters on each screen match the list beside it.

Play the prototype

Intrinsic load

How hard the skill itself is: how many things the player has to hold in mind and relate at once.

Extraneous load

Effort spent on the presentation rather than the skill: clutter, waiting, searching for information, unclear feedback.

Germane load

Effort that builds lasting understanding: noticing patterns, explaining why, practising recall.
